# ARTchive ✦

Portfólio de página única que apresenta os trabalhos de **Luiza Chaves** em social media e design.

Este é meu primeiro projeto de programação: um site feito do zero com **HTML, CSS e JavaScript**, sem frameworks.

<!-- Se o site estiver publicado no Netlify, troque a linha abaixo pelo link real -->
🔗 **Site no ar:** [https://artchive-luiza.netlify.app]

## Seções

- **Início:** capa com o nome e a chamada "conheça meu trabalho"
- **Trabalhos:** galeria com filtros por categoria
  - Peças estáticas (Sanfillipo jóias, Agama)
  - Identidade visual (Nega Doce: primeira e nova identidade)
  - Apresentações (Bala Fini)
  - Revista (Street Atitude)
  - Perfil pessoal
- **Quem sou eu?:** apresentação da Luiza
- **Contato:** e-mail e telefone

## O que o site faz

- Funciona no celular e no computador (layout responsivo)
- Filtra os trabalhos por categoria
- Amplia as imagens ao clicar, com opção de abrir em tamanho original
- Pode ser usado só com o teclado: o foco fica dentro da imagem ampliada e a tecla Esc fecha
- Respeita quem prefere menos animações no sistema
- Visual inspirado em colagens e revistas: estrelas, fitas adesivas e recortes

## Tecnologias

- **HTML:** estrutura e conteúdo da página
- **CSS:** cores, fontes, layout em grade (`grid`) e adaptação para celular (`@media`)
- **JavaScript:** menu do celular, filtros e imagem ampliada
- **Fontes:** Anton, Instrument Serif e Inter (Google Fonts)

## Estrutura dos arquivos

```
ARTchive/
├── index.html          ← conteúdo da página
├── css/
│   └── style.css       ← aparência
├── js/
│   └── script.js       ← comportamentos
└── images/
    ├── capa/           ← capa do portfólio
    ├── sobre/          ← foto da Luiza
    └── trabalhos/      ← páginas dos trabalhos (versão grande e "-mini")
```

## Como ver no computador

1. Baixe ou clone este repositório.
2. Dê dois cliques no arquivo `index.html`.
